Proyectos

Module 01 — Plataforma de inventario

InventoryPlatform

Sistema de control de inventario con catálogo de productos, movimientos de stock por ubicación, un flujo de solicitud → aprobación → entrega por área, y sesiones de conteo físico reconciliables contra el sistema. El backend y el frontend viven en repos separados, comunicados por una API REST.

Backend

.NET 10 ASP.NET Core Web API EF Core + SQL Server xUnit

Clean Architecture en cuatro capas (Domain / Application / Infrastructure / Api), reglas de dominio explícitas —el stock se calcula, no se cachea— y documentación con OpenAPI + Scalar.

Frontend

Blazor Server (.NET 10) HttpClient tipado

Sin acceso directo a datos: todo pasa por la API. Comparte los DTOs del backend por referencia de proyecto. Pantallas para productos, movimientos, solicitudes y conteos.
